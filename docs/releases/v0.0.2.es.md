## Skryensya UI 0.0.2

La segunda versión, todavía distribuida como archivos de un GitHub Release (nada se publica en npm). Los paquetes son los de la 0.0.1 más el CLI.

### Builds por componente

- `@skryensya/react` y `@skryensya/vanilla` traen un `dist/` compilado con un módulo por componente. Sus `exports` apuntan ahí, así que `@skryensya/react/button` carga Button y lo que Button necesita, no el kit entero. Los tipos siguen saliendo de las fuentes, que también vienen en el paquete.
- `@skryensya/core` publica un manifiesto de instalación (`@skryensya/core/install-manifest.json`): para cada componente, la hoja de estilos que necesita (con las que esa importa), su import de React y su montaje en Vanilla, con los selectores que vigila la carga automática.
- Ambos bindings reexportan el CSS de core, así que instalar un binding basta.

### El CLI `skryensya`

- `@skryensya/cli` se suma a los paquetes y comparte su versión: `skryensya list`, `info <nombre>` y `add <nombre>` conectan un componente en un proyecto Next, Astro, React Router, TanStack Start o Vite (su hoja de estilos y sus paquetes; nunca copia código).
- Sabe a qué versión pertenece (`skryensya --version`), y `add` instala los archivos de esa versión por URL: el binding junto con los paquetes de core e íconos de los que depende, porque nada está en un registro.

### Componentes nuevos y cambios

- Resizable (paneles plegables), ScrollStack, ScrollExpand, MorphStack, Dock, DialogStack, CompareSlider, ScrollHint, Message, ExpressiveAvatar, Shimmer, reproductores de video y audio, un recortador de imágenes y AppShell.
- Core: las celdas de Grid se encogen con su pista en vez de quedar abiertas por su contenido más ancho; `--font-family-heading`; JetBrains Mono viene con el kit.
- El acento se deriva de una sola semilla; se rehicieron los modos de accesibilidad y el movimiento.
- Integraciones de React para React Hook Form y TanStack Table.
- Vanilla: la paleta de comandos se cierra antes de seguir un enlace a la misma página.

### Documentación

- Cada página de componente tiene una sección de instalación generada desde el manifiesto: cómo instalarlo, qué hojas necesita y cuándo y cómo se monta (automáticamente con `initComponents()` o por su cuenta).
- El catálogo muestra miniaturas pre-renderizadas y arma un ejemplo solo cuando se abre.

### Verificación

- `pnpm check`
- Cada archivo empaquetado se abre y se revisa: su versión, y que cada archivo que nombran sus `exports` esté dentro (`node scripts/release.ts verify`).
