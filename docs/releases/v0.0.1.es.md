## Skryensya UI 0.0.1

La primera versión: aquí empieza el registro de contratos. Se distribuye como archivos de un GitHub Release (nada se publica en npm).

### Qué es

- **Un contrato por componente.** Cada una de las 100 familias se declara una sola vez en `@skryensya/core`: sus partes, opciones, styling hooks y reglas de accesibilidad. Los bindings de React y Vanilla cumplen ese mismo contrato, y los gates comprueban que ambos produzcan el mismo DOM y el mismo árbol de accesibilidad.
- **Tres formas de usar un mismo kit.** `@skryensya/core` (tokens, CSS y contratos), `@skryensya/react` y `@skryensya/vanilla`, que mejora HTML escrito a mano y monta cada componente por separado.
- **Tokens y modos.** Claro, oscuro y alto contraste; cuatro apariencias (plain, tactile, brutalist, frosted); densidad, radio y movimiento como dimensiones.
- **Alrededor del kit.** Adaptadores de íconos para Lucide, Material y Phosphor, además de gráficos, un editor y herramientas de desarrollo.

### Para agentes

- Cada contrato se compila en un manifiesto que sirve el servidor MCP: un agente propone un árbol de uso, `validate_ui` lo comprueba contra los contratos y emite el markup, el código React y las hojas de estilo que necesita.

### Verificación

- `pnpm check`
- `pnpm build`
- Archivos empaquetados para los paquetes publicados.
