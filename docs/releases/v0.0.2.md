## Skryensya UI 0.0.2

The second release, still distributed as GitHub Release tarballs (nothing is published to npm). The package set is the one from 0.0.1 plus the CLI.

### Per-component builds

- `@skryensya/react` and `@skryensya/vanilla` ship a built `dist/` with one module per component. Their tarballs' `exports` point at it, so `@skryensya/react/button` loads Button and what Button needs, not the kit. Types stay on the sources the tarballs also carry.
- `@skryensya/core` publishes an install manifest (`@skryensya/core/install-manifest.json`): for every component, the stylesheet it needs (with the sheets that one imports), its React import, and its Vanilla mount with the selectors the auto-loader watches.
- Both bindings re-export core's CSS, so installing a binding is enough.

### The `skryensya` CLI

- `@skryensya/cli` joins the release set and shares its version: `skryensya list`, `info <name>` and `add <name>` wire a component into a Next, Astro, React Router, TanStack Start or Vite project (its stylesheet and packages; it never copies source).
- It knows which release it belongs to (`skryensya --version`), and `add` installs that release's tarballs by URL, the binding together with the core and icon packages it depends on, since nothing is on a registry.

### New components and changes

- Resizable (collapsible panels), ScrollStack, ScrollExpand, MorphStack, Dock, DialogStack, CompareSlider, ScrollHint, Message, ExpressiveAvatar, Shimmer, video and audio players, an image cropper, and AppShell.
- Core: Grid cells shrink with their track instead of being held open by their widest content; `--font-family-heading`; JetBrains Mono ships with the kit.
- Accent is derived from one seed; accessibility modes and motion were reworked.
- React integrations for React Hook Form and TanStack Table.
- Vanilla: the command palette closes before following a link to the same page.

### Documentation

- Every component page has an Installation section generated from the install manifest: how to install it, which sheets it needs, and when and how it mounts (automatically with `initComponents()`, or on its own).
- The catalog shows pre-rendered thumbnails and builds an example only when it is opened.

### Verification

- `pnpm check`
- Every tarball is opened and checked: its version, and that every file its `exports` name is inside it (`node scripts/release.ts verify`).
