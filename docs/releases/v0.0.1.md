## Skryensya UI 0.0.1

The first release: the contract ledger starts here. Distributed as GitHub Release tarballs (nothing is published to npm).

### What it is

- **One contract per component.** Each of the 100 families is declared once in `@skryensya/core`: its parts, options, styling hooks and accessibility rules. The React and Vanilla bindings both realize that same contract, and the gates check that they land on the same DOM and the same accessibility tree.
- **Three bindings of one kit.** `@skryensya/core` (tokens, CSS and the contracts), `@skryensya/react`, and `@skryensya/vanilla`, which enhances authored HTML and mounts each component on its own.
- **Tokens and modes.** Light, dark and high contrast; four appearances (plain, tactile, brutalist, frosted); density, radius and motion as dimensions.
- **Around the kit.** Icon adapters for Lucide, Material and Phosphor, plus charts, an editor and devtools.

### For agents

- Every contract compiles into a manifest that the MCP server serves: an agent proposes a usage tree, `validate_ui` checks it against the contracts and emits the markup, the React source and the stylesheets it needs.

### Verification

- `pnpm check`
- `pnpm build`
- Packed release tarballs for the published surface packages.
